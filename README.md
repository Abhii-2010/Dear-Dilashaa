# Dear Dilashaa ♡

A romantic, animated React + Vite website. This first milestone contains the welcome page.

## Run locally

1. Install Node.js (LTS) if it is not already installed.
2. Extract this folder.
3. Open a terminal in this folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL Vite prints (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Music

The welcome page currently has a music UI placeholder; it does not play audio yet. When you choose a song you have permission to use, add it as `public/song.mp3` and wire the player to that file in a later step.
